Cài đặt Access Token

Cách lấy token

  1. Mở Graph API Explorer.
  2. Chọn App của bạn → User Token → thêm quyền: ads_read, ads_management, business_management, pages_show_list, pages_read_engagement.
  3. Bấm Generate Access Token, copy và dán vào ô trên.
  4. Có thể đổi sang token dài hạn tại Access Token Debugger.

Token chỉ được lưu trong trình duyệt này và chỉ gửi tới graph.facebook.com.
